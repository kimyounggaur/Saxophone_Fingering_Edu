# SaxTone 청음 랩

SaxTone 2.0과 3.0을 **귀로 비교하기 위한** 단일 HTML 페이지입니다. 이 저장소의 엔진 코드(`lib/sax-synth.ts`, `lib/sax-model.ts`)를 그대로 번들하므로 앱에서 나는 소리와 같은 소리를 비교합니다. 앱 빌드·배포에는 포함되지 않습니다.

음색이 좋은지는 측정으로 보증할 수 없습니다. 이 도구는 판단을 대신하지 않고, **같은 조건에서 번갈아 듣고 그 결과를 기록**하게 해 줍니다.

## 만들고 열기

```bash
node scripts/audio-calibration/listening-lab/build.mjs <출력 폴더>
```

`<출력 폴더>`에 두 파일이 생깁니다. esbuild는 이미 `node_modules`에 있어 따로 설치하지 않습니다.

| 파일 | 용도 |
| --- | --- |
| `sax-lab.html` | 페이지 조각(제목·스타일·마크업·스크립트). 아티팩트처럼 조각을 감싸 주는 곳에 게시할 때 |
| `sax-lab-standalone.html` | 완전한 HTML 문서. 파일로 열거나 정적 호스팅할 때 |

외부 요청도, 오디오 파일도 없습니다(약 80KB). 소리는 "재생"을 누른 뒤에만 납니다.

## 할 수 있는 일

- **같은 음량으로 번갈아 듣기** — A-가중·무음 구간 제외 음량을 0.05dB 이내로 맞춥니다. 최대 파형이 0.9를 넘으면 두 소리를 함께 줄입니다. "음량 맞춤"을 끄면 같은 전체 크기에서 엔진 고유의 균형으로 비교합니다.
- **재생 중 전환** — 1·2 키 또는 버튼. 같은 위치에서 20ms 크로스페이드로 이어집니다. Esc는 정지, 반복 재생은 켜고 끌 수 있습니다.
- **블라인드 테스트** — 순서를 무작위로 섞고 정체를 가립니다. 두 소리를 모두 들어야 답할 수 있고, "실제 색소폰 같음"과 "듣기 좋음"을 따로 집계하며, 답을 고르면 공개합니다. 라운드 중에는 3.0 조절을 잠급니다(3.0만 바뀌어 정체가 드러나므로).
- **재료** — 한 음, 한 옥타브 음계, 짧은 선율, 음역 전체 걷기. 악기는 알토·테너·소프라노, 시작음과 다이내믹(세기)을 고를 수 있습니다.
- **분석 그림** — 같은 색 눈금의 스펙트로그램, 선택한 음의 배음 프로필(전체 소리에서 각 배음이 차지하는 크기). 알토는 실제 녹음에서 측정한 값을 함께 그리고 오차(`compare.py`와 같은 통계)를 표시합니다. 표로도 볼 수 있습니다.
- **3.0 음색 조절** — 밝기·숨소리·어택 길이·텅잉·생동감·비브라토 3종·끝맺음 9개 슬라이더. 바꾸면 3.0만 다시 렌더링합니다.
- **기록 복사** — 악기·재료·슬라이더·블라인드 집계·메모를 JSON으로 복사합니다. 마음에 드는 값은 `lib/sax-model.ts` 상수나 앱 기본값에 반영하는 근거가 됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `template.html` | 페이지 틀(스타일·마크업). 색은 SaxHands 팔레트 + 검증된 데이터 시각화 팔레트(2.0 파랑, 3.0 주황, 녹음 아쿠아) |
| `build.mjs` | esbuild로 번들해 위 두 파일을 씀 |
| `src/render.ts` | `SaxSynthEngine`을 `OfflineAudioContext`에서 구동해 마스터 체인(하이패스→컴프레서→룸→마스터)까지 거친 소리를 렌더링 |
| `src/player.ts` | 두 클립이 한 시간축을 공유하는 A/B 재생기(전환 시 위치 유지) |
| `src/dsp.ts` | FFT, 스펙트로그램, A-가중 게이트 음량과 음량 맞춤, 배음 프로필(`analyze_ref.py`의 이식) |
| `src/phrases.ts` | 음·음계·선율·음역 걷기(모든 음이 악기 음역 안에 들어가도록 시작음을 제한) |
| `src/charts.ts` | 스펙트로그램(캔버스)과 배음 프로필(SVG) 그리기 |
| `src/ref-alto.ts` | 알토 녹음에서 측정한 배음 레벨(숫자만, 오디오 없음) |
| `src/main.ts` | 상태·화면·블라인드·기록 |

단위 테스트는 `tests/listening-lab.test.mjs`(`npm run test:unit`에 포함)이며 `dsp.ts`와 `phrases.ts`를 검증합니다. `dsp.ts`의 배음 측정은 Python 분석 스크립트와 같은 값을 내는 것을 확인했습니다.

## 한계

- **귀를 대신하지 못합니다.** 숫자로 "녹음과 비슷한 신호"는 확인할 수 있지만 듣기 좋은지는 사람이 판단해야 합니다. 휴대전화 스피커와 이어폰 양쪽에서 들어 보세요.
- **비교 곡선은 알토 한 세트뿐입니다.** 출처는 npm `tonejs-instrument-saxophone-mp3@1.1.2`(tonejs-instruments, Karoryfer 제공, CC BY 3.0)이고 무음 트리밍·온/오프 램프 등 편집을 거친 샘플입니다. 3.0은 이 자료에 맞춰 조정했으므로 알토 곡선과의 일치는 **새 자료로 검증된 것이 아니라 조정에 쓴 자료와의 일치**입니다. 테너·소프라노는 비교 곡선이 없습니다.
- 렌더링은 브라우저에서 합니다. 첫 렌더는 JIT 때문에 조금 오래 걸릴 수 있고(데스크톱 0.5~0.7초), 휴대전화에서의 시간은 측정하지 않았습니다.
