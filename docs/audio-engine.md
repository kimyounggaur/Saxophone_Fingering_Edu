# SaxTone 2.0 오디오 엔진

SaxHands의 기준음은 외부 음원 파일을 내려받지 않는 Web Audio 기반 색소폰 모델링 합성음입니다. 기존 단일 사인파를 대체하며, 오프라인 PWA에서도 알토·테너·소프라노의 서로 다른 음색과 정확한 기준 음정을 제공합니다.

## 신호 구조

```text
악기·음역별 36배음 PeriodicWave
  → 리드 소프트 새추레이션
  → 3단 관 공명 포먼트 EQ
  → 음역 추적 로우패스
                         ┐
필터링된 호흡 노이즈 ───┼→ 클릭 방지 ADSR → DC 차단 → 컴프레서 → dry/wet room → 음량
키 터치 트랜지언트 ─────┘

5.0–5.5Hz 지연 비브라토 + 저속 미세 드리프트 → carrier detune
```

- 알토·테너·소프라노마다 배음 감쇠, 짝수 배음 비율, 3개 공명점, 밝기, 호흡량, 비브라토가 다릅니다.
- 시작 시 작은 피치 스쿠프와 키 접촉음을 넣고, 약 0.4초 뒤 비브라토가 자연스럽게 증가합니다.
- 최대 두 음만 동시에 유지합니다. 세 번째 음은 가장 오래된 음을 짧게 릴리스하여 클릭 없이 교체합니다.
- 마스터 컴프레서와 짧은 스테레오 룸 응답으로 모바일 스피커에서도 피크와 거친 고역을 억제합니다.
- 모든 노이즈와 룸 응답은 기기 샘플레이트에 맞춰 한 번만 생성해 재사용합니다.

## 음정과 악기 처리

기준음 기준이 `실제로 들리는 실음`이면 기존 `concertMidi()` 결과를 합성 엔진에 전달합니다. `악보의 기보음`이면 written MIDI를 그대로 전달합니다. A4는 440Hz 12평균율이며 기존 이조 규칙은 다음과 같습니다.

| 악기 | 기보음에서 실음으로 |
| --- | --- |
| 소프라노 | -2반음 |
| 알토 | -9반음 |
| 테너 | -14반음 |

## 모바일·접근성 안전장치

- AudioContext는 첫 재생 또는 자동 음색 켜기 시에만 만듭니다.
- 자동 재생은 사용자의 실제 탭 안에서 먼저 컨텍스트를 깨운 뒤 애니메이션 지연을 적용합니다.
- 빠르게 음을 바꾸면 이전 예약 타이머를 취소합니다.
- 연습 문제는 정답 공개 전 수동·자동 음색을 모두 막아 음정 누설을 방지합니다.
- 앱이 숨겨지거나 페이지를 떠나면 예약 음과 활성 보이스를 릴리스합니다.
- 음량 0%는 최소 볼륨으로 치환하지 않고 실제 무음으로 처리합니다.
- 합성음은 실제 연주 녹음이 아님을 설정 화면에 명시합니다.

## 자동 검증

`tests/sax-synth.test.mjs`는 다음 불변식을 확인합니다.

- MIDI와 440Hz 12평균율 변환
- 세 악기 프로필의 구분
- 저·중·고역 배음의 유한값, 대역 제한, 사인파 회귀 방지
- 고역일수록 조금 빠른 어택과 모든 음역의 클릭 방지 릴리스 순서

주관적인 음색 평가는 실제 휴대전화 스피커와 이어폰에서 별도 청취 검수가 필요합니다. 향후 소유하거나 라이선스가 확인된 24-bit 드라이 멀티샘플을 같은 엔진 API 뒤에 추가할 수 있으며, 그 경우에도 현재 모델링 엔진은 오프라인·로딩 실패용 fallback으로 유지합니다.
